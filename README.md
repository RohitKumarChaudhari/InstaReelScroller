# 📱 InstaReelScroller

**InstaReelScroller** is a fun Python automation project that uses Selenium to open Instagram and automatically scroll through Reels, just like a real user would! Perfect for learning browser automation and simulating human-like interactions.

---

## 🎯 What It Does

- Launches Instagram in a browser
- Logs in using your credentials (optional)
- Navigates to the Reels section
- Scrolls through reels with timed intervals
- Simulates real user behavior for a natural feel

---

## 🧰 Tech Stack

- Python 🐍
- Selenium WebDriver
---

## 🚀 How to Use

### 1. Clone the Repository

```bash
git clone https://github.com/RohitKumarChaudhari/InstaReelScroller.git
cd InstaReelScroller
```

### 4. Run the Script
```bash
python main.py
```
```
The script will open Instagram, navigate to Reels, and begin scrolling automatically.
```

## ⚠️ Important Notes
- Make sure you're logged in to Instagram or provide your credentials securely.  
- Do not abuse automation on Instagram – it may violate their Terms of Service.  
- This project is for educational purposes only.

You can modify:
